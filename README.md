## 🚀 HƯỚNG DẪN KHỞI CHẠY (LOCAL & PRODUCTION)

```bash
# Cài đặt thư viện (nếu chưa cài)
npm install

# Khởi chạy máy chủ phát triển
npm run dev

# Xây dựng bản phát hành sản phẩm
npm run build
npm start
```
Truy cập: `http://localhost:3000`

---

## 📱 ĐÓNG GÓI THÀNH APP ĐIỆN THOẠI (iOS / ANDROID)

```bash
# 1. Cài đặt Capacitor
npm install @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios

# 2. Khởi tạo Capacitor
npx cap init "Ky Thu Co Mon" "com.tuvi.nexus" --web-dir "out"

# 3. Đồng bộ và mở trong Android Studio / Xcode
npm run build
npx cap add android
npx cap sync
npx cap open android
```
